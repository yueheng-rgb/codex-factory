# Product architecture

1. Define minimum user roles and their concrete goals.
2. Map the primary success path plus empty, validation, permission, conflict, and recovery paths.
3. Draft the first-version page tree, API contracts, core entities/relations, and server-side permission boundaries.
4. List the completeness checklist and ten most likely failure points for the chosen app type.
5. Select the smallest end-to-end slice and the exact real user paths that must pass before expansion.
