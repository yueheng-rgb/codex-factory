# E-commerce Mini Program — Requirement

## Project Overview
Build a WeChat mini-program for a fashion e-commerce store with product browsing, cart, orders, and payment.

## Core Features
1. WeChat login (wx.login)
2. Product catalog with categories, search, and filters
3. Shopping cart with stock validation
4. Order creation and payment (WeChat Pay mock for MVP)
5. Order history and status tracking
6. User profile and address management
7. Admin backend for product/inventory/order management

## Technical Preferences
- Frontend: WeChat Mini Program (WXML/WXSS)
- Backend: REST API (Node.js or Java Spring Boot)
- Database: PostgreSQL or MySQL
- File storage: Cloud storage for product images
- CI: Not required for MVP
