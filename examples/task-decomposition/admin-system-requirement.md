# Admin Management System — Requirement

## Project Overview
Build a hospital admin management system for doctors to manage patient records, appointments, and prescriptions.

## Core Features
1. Doctor login/authentication (JWT-based)
2. Patient CRUD management
3. Appointment scheduling with calendar view
4. Prescription management with drug interaction warnings
5. Role-based access: Admin, Doctor, Nurse
6. Dashboard with daily statistics (patient count, appointments, revenue)
7. Export reports as PDF

## Technical Preferences
- Backend: REST API
- Frontend: React + TypeScript
- Database: PostgreSQL
- CI: GitHub Actions
