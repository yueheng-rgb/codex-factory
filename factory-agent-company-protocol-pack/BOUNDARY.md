4. Large-project context only — not for small/medium projects.
5. All gating must be verifier-based — no score-based PASS/FAIL.
6. Compressed summary is NOT evidence.
7. Main Agent must not write worker implementation scope.

9. Verifier and Integrity Checker are readonly.
