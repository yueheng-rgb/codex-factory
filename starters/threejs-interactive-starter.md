# Three.js Interactive Starter

## 适合项目
- 3D 产品展示
- 虚拟展厅/空间
- 交互式 3D 地图
- 3D 数据可视化
- WebGL 创意原型

## 不适合项目
- 需要复杂表单/数据库的常规 Web 应用
- 微信小程序
- 纯 2D 网站

## 推荐技术栈
- **构建：** Vite
- **语言：** TypeScript
- **3D 引擎：** Three.js
- **UI 层：** HTML/CSS 或 React 面板
- **状态：** 自定义状态管理器
- **测试：** Playwright (截图对比 + 按钮点击)

## 推荐目录结构
```
src/
├── scene/               # 场景层
│   ├── Scene.ts         # 场景初始化
│   ├── Camera.ts        # 相机控制
│   ├── Lights.ts        # 灯光设置
│   └── objects/         # 场景对象
│       ├── Ground.ts
│       └── Building.ts
├── objects/             # 可交互物体
│   ├── InteractiveObject.ts  # 基类
│   └── Product.ts
├── ui/                  # UI 面板层
│   ├── InfoPanel.ts
│   └── Controls.ts
├── state/               # 状态管理
│   ├── AppState.ts
│   └── InteractionState.ts
├── utils/
│   └── AssetLoader.ts   # 资源加载
├── main.ts              # 入口
└── style.css            # 全局样式
```

## 分层架构
```
┌─────────────────────────┐
│      UI 面板层           │  ← 2D 覆盖层（按钮、信息面板）
├─────────────────────────┤
│      场景对象层          │  ← 3D 可交互物体
├─────────────────────────┤
│       场景层             │  ← 灯光、相机、背景
├─────────────────────────┤
│       状态管理层         │  ← 应用状态、选中状态
└─────────────────────────┘
```

## 核心模块
1. **场景初始化**（相机、灯光、渲染器）
2. **至少 1 个可交互物体**（点击/悬停有反馈）
3. **UI 面板**（信息展示、操作按钮）
4. **状态管理**（选中状态、相机状态）

## 最小闭环
- 一个可交互的 3D 场景
- 至少 1 个可点击/交互的物体（hover 高亮 + click 弹信息）
- 基本 UI 面板（标题、返回按钮等）
- 能在浏览器中查看

## 常见坑
- ❌ 不限制帧率（移动端发烫）
- ❌ 没做资源预加载（加载时黑屏）
- ❌ 交互没有视觉反馈
- ❌ 移动端不降级（polygon 数过高）
- ❌ 相机控制太自由（用户迷失方向）
