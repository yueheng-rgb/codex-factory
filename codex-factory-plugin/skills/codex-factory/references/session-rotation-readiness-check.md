# Verifier Module: session-rotation-readiness-check

## Metadata
- **Verifier ID**: `session-rotation-readiness-check`
- **Version**: 1.0.0
- **Phase**: H18
- **Category**: continuity-gate
- **Priority**: P1 (Blocking Caveat)
- **nativeGenerated**: true

## Purpose
Verify that a worker session is ready for rotation. Checks that a valid handoff artifact exists, its SHA256 is valid, and the factoryctl verify preflight passes. Ensures session continuity is not broken by rotation.

## Target Gate
`SESSION_ROTATION_READY`

## Evidence Source
- **Primary**: Handoff JSON artifact (generated by `generate-handoff.ps1`)
- **Secondary**: `handoff-verify.ps1` output
- **Tertiary**: `AGENT_PROGRESS.jsonl` — `handoff_generated` and `session_rotated` events
- **Quaternary**: Worker contract — `integrationHandoff.path`

## Check Logic

### Step 1: Verify Handoff Exists
- Check that a handoff artifact exists at the path specified in the worker contract's `integrationHandoff.path`.
- If no handoff exists → **FAIL: HANDOFF_MISSING** (P1)

### Step 2: Validate Handoff SHA256
- Compute SHA256 of the handoff artifact.
- Compare against the SHA256 recorded in the handoff's metadata or in `AGENT_PROGRESS.jsonl` handoff event.
- If SHA256 mismatch → **FAIL: HANDOFF_SHA256_MISMATCH** (P0)
- If no SHA256 recorded → **CAVEAT: HANDOFF_SHA256_UNVERIFIED** (P2)

### Step 3: Run Handoff Verify
- Execute `handoff-verify.ps1` against the handoff artifact.
- Check exit code: 0 = valid, non-0 = invalid.
- If verify fails → **FAIL: HANDOFF_VERIFY_FAILED** (P0)

### Step 4: Check Compression Level
- Read `compressionLevel` from worker contract or latest progress event.
- If compression level >= 3 → rotation is mandatory (this check is informational; the rotation-readiness gate verifies the handoff quality, not the trigger).
- If compression level == 2 → rotation is strongly recommended.

### Step 5: Verify Evidence Coverage
- Check that all evidence entries created before the handoff timestamp have valid SHA256 hashes recorded.
- Check that the handoff references all evidence entries in its scope.
- If evidence entries exist without SHA256 in handoff → **CAVEAT: EVIDENCE_NOT_FULLY_HASHED** (P2)

### Step 6: Factoryctl Preflight
- Run `factoryctl verify --preflight` to check all gates before rotation.
- If any P0 gate fails → rotation blocked until resolved.
- If only P1/P2 gates fail → rotation may proceed with caveats.

## PASS Criteria
- Handoff artifact exists at declared path.
- Handoff SHA256 is valid and matches recorded hash.
- `handoff-verify.ps1` passes (exit code 0).
- All evidence entries in scope are referenced with valid SHA256 hashes.
- `factoryctl verify --preflight` returns no P0 failures.

## FAIL Criteria
| Failure Mode | Priority | Description |
|---|---|---|
| `HANDOFF_MISSING` | P1 | No handoff artifact found at declared path. |
| `HANDOFF_SHA256_MISMATCH` | P0 | Handoff SHA256 does not match recorded hash. |
| `HANDOFF_VERIFY_FAILED` | P0 | handoff-verify.ps1 returned non-zero exit code. |
| `HANDOFF_EMPTY` | P0 | Handoff artifact exists but contains no substantive data. |
| `HANDOFF_STALE` | P1 | Handoff generatedAt is older than latest evidence write timestamp. |

## CAVEAT Criteria
| Caveat | Priority | Description |
|---|---|---|
| `HANDOFF_SHA256_UNVERIFIED` | P2 | Handoff exists but SHA256 was not independently verified. |
| `EVIDENCE_NOT_FULLY_HASHED` | P2 | Some evidence entries in scope lack SHA256 in handoff. |
| `COMPRESSION_LEVEL_2_ROTATION_RECOMMENDED` | P2 | Compression level 2: rotation recommended but not forced. |

## False Positive Risks
1. **Handoff written asynchronously**: Handoff may be written by a background process after the check runs. Mitigation: Check for in-flight handoff generation events in AGENT_PROGRESS.jsonl before flagging HANDOFF_MISSING.
2. **SHA256 recorded in different format**: SHA256 may be in uppercase hex while computed hash is lowercase. Mitigation: Normalize case before comparison.
3. **Evidence entry timing**: Evidence entries written between handoff generation and rotation check. Mitigation: Allow a grace window; only flag entries older than handoff timestamp + 60 seconds.

## Dependencies

## Integration
Invoked by `factoryctl session-rotate --preflight`. Called before any session rotation operation. Blocks rotation if P0 failures detected.
