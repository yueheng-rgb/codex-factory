# H18 Resource Pack Boundary Rules

## Mandatory Rules
1. No scoring system may be packaged as a core PASS/FAIL gate.
2. No unverified Codex capability claim may be packaged as VERIFIED_FACT.
3. No compressed summary may be substituted for primary evidence.
4. Failure-router is excluded from all core/runnable pack paths.
5. Historical evidence from DRY19/DRY20/DRY23/P2/H17/DRY24 must not be rewritten.
6. No final delivery ZIP may be created during H18.
7. All gating must be verifier-based (binary check, not weighted score).
8. Main Agent must not undeclared-write worker implementation scope.
9. Integrator is sole merge owner.
10. Verifier is readonly.

## Reference Material Rules
- Reference-archive material must carry a stability marker and warning about staleness.
- Deprecated material must cite its replacement.
- Scoring systems in reference must include SCORING_SYSTEM_GATE warning.

## Evidence Rules
- Evidence hierarchy: Verifier result > Transcript > Registry entry > Progress event > Summary.
- Summary is untrusted evidence unless corroborated by verifier result.
- No manual PASS-only verdict.
- No expectedClass-only verdict.
- No generic FAIL.
