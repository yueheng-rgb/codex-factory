# OVERCLAIM_POLICY.md
> Part of: FACTORY-EVIDENCE-TAXONOMY-0 / F

## Policy
- Every claim MUST be tagged with evidence level and supported boolean
- Claim must not exceed evidence level
- Caveat required for E3 (live-inspected not full E2E), E4 (fixture not real), E6 (local not production)
- "Factory superiority" must reference specific tested tasks
- v0.5 local tooling scope supported only by E4/E5/E6
- Release approval is USER DECISION, not technical evidence

## Blocked Claims
- "Proven" without evidence level
- "Universal" / "always" / "guaranteed"
- "Production ready" without E7
- "Works everywhere" without E8
- Claims from snapshot/dashboard/chat as primary
- Claims from FOREIGN_CONTEXT as current project evidence

## Upgrading Claims
- E1→E4 claim requires new execution evidence
- E6→E7 claim requires production deployment (out of v0.5 scope)
- Never upgrade by reinterpreting same evidence
