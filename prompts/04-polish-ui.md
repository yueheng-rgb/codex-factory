# UI 打磨提示词

> 在核心功能实现后使用，优化界面。

---

请优化当前项目的 UI。

## 执行要求

### 1. 检查四态完整性
每个页面/组件是否都有：
- loading 状态（骨架屏/spinner）
- empty 状态（引导文案+操作按钮）
- error 状态（错误提示+重试）
- success 状态（正常展示）

### 2. 避免 AI 味
- 去掉无意义的紫色渐变
- 去掉过多的 emoji
- 调整过大的圆角（降到 8-12px）
- 让配色更专业

### 3. 响应式检查
- 375px 下核心功能可用
- 按钮不小于 44x44px
- 文字可读（不小于 14px）

### 4. 交互反馈
- 按钮有点击状态
- 操作有 loading 状态
- 操作成功/失败有提示
- 危险操作有确认弹窗
