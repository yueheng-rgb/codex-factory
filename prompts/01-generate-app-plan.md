# 生成应用计划提示词

> 在用户确认项目方向后使用。

---

基于我们已经确认的应用类型和需求，请生成详细的实现计划。

## 执行要求

### 1. 确认范围
- 列出第一版要实现的完整功能清单
- 列出第一版明确不做的功能
- 确认技术栈选型

### 2. 制定实现顺序
将第一版功能按依赖关系排序：
- 先做基础设施（项目脚手架、数据库）
- 再做核心功能（按用户路径）
- 最后做辅助功能

### 3. 估算文件清单
列出预计要创建/修改的文件：
- 每个文件的用途
- 文件之间的依赖关系

### 4. 输出格式
```
## 实现计划

### 功能清单（第一版）
- [ ] 功能 1
- [ ] 功能 2
- ...

### 不做的功能
- 功能 A（原因）
- ...

### 实现顺序
1. 阶段 1：[描述] — 预计文件：[N] 个
2. 阶段 2：[描述] — 预计文件：[N] 个
3. ...

### 文件清单预览
- src/... — 用途
- src/... — 用途
```
