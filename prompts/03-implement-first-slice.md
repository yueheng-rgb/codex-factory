# 实现第一阶段提示词

> 在设计稿确认后，实现第一版最小闭环。

---

根据我们确认的设计稿，请实现第一阶段（最小闭环）。

## 执行要求

### 严格遵循设计稿
- 只实现设计稿中第一版明确列出的功能
- 不要自行扩展功能
- 不要添加设计稿中"暂不实现"的内容

### 只做最小闭环
- 让用户能完成一个真实目标
- 1-3 个核心页面
- 1-3 个核心 API
- 最少必要数据表

### 质量要求
- 每个页面必须有 loading、empty、error、success 四态
- 每个表单必须有：必填校验、提交中状态、防重复提交、成功/失败反馈
- 权限必须在服务端校验（如果适用）
- 所有 API 返回统一格式

### 完成后
- 说明如何运行（一条命令）
- 输出简短里程碑报告：
  - 创建/修改了哪些文件
  - 实现了哪些功能
  - 建议下一步做什么

### 不要做的事
- ❌ 不要自行扩展额外功能
- ❌ 不要加"暂不实现"的东西
- ❌ 不要输出长篇代码审计
