# 扩展功能提示词

> 第一版稳定后，扩展新功能。

---

基于当前项目，请实现以下功能扩展。

## 新需求

[在此描述要添加的功能]

## 执行要求

### 1. 评估影响
- 这个功能会影响哪些现有页面/API/数据表？
- 是否需要新增数据表？
- 是否需要新增 API 端点？

### 2. 保持一致性
- 新增代码的风格与现有代码一致
- API 格式与现有 API 一致
- UI 风格与现有页面一致

### 3. 更新文档
- 更新 README 中的功能列表
- 如有新的环境变量，更新 .env.example

### 4. 回归检查
- 新功能是否破坏了旧功能？
- 现有关键路径是否仍能正常工作？
