# 条件效果分析

`npm run eval:forecast` 是一个离线估算工具，用来检查“某项能力在什么假设下才可能值得用”。它不是成功率测试，也不调用模型或 Agent。

## 运行

```powershell
cd <repo>\packages\factory-cli
npm run eval:forecast
```

脚本读取 `evals/effect-assumptions.json`，输出净收益、副作用和成本抵消点。它帮助讨论评测设计，不替代真实实验。

## 它回答什么

- 如果某能力覆盖率有限，理论最大收益是多少。
- 如果误用会带来额外成本，需要多大正向效果才能抵消。
- 哪些假设最影响结论。

## 它不回答什么

- 不证明 Factory 比普通 Agent 更好。
- 不预测某个项目一定成功。
- 不统计真实 token、费用或墙钟时间。
- 不证明澄清、教学或探针一定应该启用。

## 使用方式

把 forecast 当成评测前的预算和风险草图：

1. 明确能力只覆盖哪类任务。
2. 明确误用或额外审阅的成本。
3. 再决定是否值得跑真实 native 评测。

真实结论必须来自冻结输入、可复现验收、独立 verifier 和明确失败分类。
