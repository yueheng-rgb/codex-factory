# 评测预算适配进展

## 本轮完成

- 在现有 TypeScript 评测脚本旁增加小型预算记录器，无新增依赖或服务。
- 新准备的 demo 默认每题共享 20 分钟连续墙钟、两轮 Worker；Verifier 和修复不另领预算。
- 派发前准入、实际宿主 ID 绑定、最多 30 秒等待建议、临近截止停止提示，以及未确认停止时阻止下一次派发。
- 接入已有 register、handoff、repair、summarize；普通 Agent 组也可使用同一预算命令，不要求安装 Factory。
- 保留原始观察及哈希，报告墙钟时长、超时量、轮次；Token、费用、纯执行时长保持未知。

## 验证与边界

8 项定向检查通过：5 项预算状态与边界单测，3 项现有评测 CLI 集成检查。`npm run eval:typecheck` 通过。
全部为本地离线夹具，不是新增模型实测，也不能证明成功率或费用收益。

原有 6 次开发试跑及 FAIL 记录未改写；没有派发新 Agent，没有启动 18 次正式对比。
这次改善的是评测可控性，不是 Agent 解题效果。

当前控制器必须读取 action 并实际调用宿主停止工具。close 返回仅表示已请求关闭；要取得终止观察才能解除活动占位。
控制器暂停时没有独立看门狗，因此不声称硬超时保证。未知宿主状态不自动恢复，恢复型 thread 观察暂不计为预算确认完成。
完整质量汇总仍要求有效交接，超时中断需同时保留预算报告并单列，不能从尝试清单删除。
