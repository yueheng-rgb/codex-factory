# R2.3-I Promotion Policy

## Skill Status Ladder (Full)

| Status | Definition | Requirements | Set By |
|--------|-----------|-------------|--------|
| `candidate` | Proposed but not reviewed | Registry entry exists | Librarian |
| `adapted` | Modified from external source | Source identified, changes documented | Librarian |
| `verified` | Basic review passed | Librarian + Security + Architect review | Integrator |
| `auditPassed` | Static audit passed | Skill Audit Pipeline PASS or pass_with_controls | Security Agent |
| `factoryRuntimeVerified` | Proven in Factory runtime | Loaded in real project, behavior difference confirmed, usage ledger recorded | Verifier + Integrator |
| `realAgentVerified` | Proven in real Codex session | Agent Run Packet consumed by real Codex agent, behavior observed | Human + Verifier |
| `multiProjectVerified` | Proven across project types | At least 3 different project types with benchmark evidence | Verifier |
| `quarantine` | Security risk detected | Audit pipeline flagged critical findings | Security Agent |
| `deprecated` | No longer recommended | Superseded, broken, or unsafe | Librarian |

## Promotion Rules

### To `factoryRuntimeVerified`:
- MUST have auditPassed
- MUST be loaded by skill-content-loader in a real project
- MUST produce observable behavior difference (with vs without skill)
- MUST have skill usage ledger entries
- MUST have handoff records
- MUST pass all verification checks

### To `realAgentVerified`:
- MUST have factoryRuntimeVerified
- MUST have ARP generated by bridge
- MUST have evidence of real Codex agent consumption
- MUST have behavior evidence from real agent session

### To `multiProjectVerified`:
- MUST have factoryRuntimeVerified
- MUST have benchmark evidence from 3+ project types
- MUST have consistent behavior across all types

## Forbidden Promotions

- ❌ Registry import → verified (must go through pipeline)
- ❌ Static audit → runtimeVerified (must have behavior evidence)
- ❌ Single project → multiProjectVerified (must have 3+)
- ❌ Simulated context → realAgentVerified (must be real Codex session)
- ❌ auditPassed → runtimeVerified without live trial (R2.3-H gate)
