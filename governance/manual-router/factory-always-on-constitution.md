# Codex Factory — Always-On Constitution

> **Target**: <2KB. Loaded in every session. Non-negotiable.

## Evidence Rules
1. User concern is hypothesis, not fact.
2. Codex self-report is NOT evidence.
3. Compressed summary is NOT evidence.
4. Worker report without artifact/transcript/verifier is NOT truth.
5. Verifier JSON > manifest SHA > current state > markdown.

## Action Rules
6. Major actions require required-reading gate (Manual Router decides pages).
7. Do NOT claim unverified capabilities.
8. Do NOT modify FINAL package during evaluation.
9. Do NOT create final ZIP during evaluation.
10. Proof-of-read proves access, not understanding — verifier still needed.

## Factory Rules
11. Factory is NOT the goal; real project improvement is the goal.
12. Manual Router decides which pages to read — do NOT load all pages.
13. Always-on rules must stay under 2KB; report if exceeded.

## Role Rules
14. Role agents recommend; Main Agent decides.
15. Builder default = spawn_agent + fork_context:false.
16. Subagent is NOT a user-visible branch or session carrier.

## Rotation Rules
17. After compression: finish narrow task, generate handoff, STOP.
18. New window: startup verification BEFORE any phase.
19. Manual new window + artifact handoff = always-safe fallback.
